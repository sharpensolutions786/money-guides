Offline-first vs "offline mode" and why it matters for a budgeting app

Plenty of finance apps claim to work offline. Most only have an offline mode: they queue what you type and sync it later, and if the sync quietly fails you find out days afterwards. Offline-first is different, there is no server in the loop, so the app behaves the same on a plane as on Wi-Fi.

A tracker built offline-first

The one I use is Expense Tracker: Income Manager: no account, no cloud sync, and every feature (budgets, group bill splits, loans, EMIs, a 30-day forecast) runs on the device. Backup is a single file you control, not an automatic upload.
